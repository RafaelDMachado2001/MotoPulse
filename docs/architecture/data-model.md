# Modelo de dados

Tipos SQLite: `TEXT`, `INTEGER`, `REAL`, `BLOB`; UUID e timestamps são TEXT. Timestamps externos têm UTC ISO-8601 e `original_offset TEXT NOT NULL` (telemetria, GPS e manutenção importada); timestamps internos (`created_at`, `updated_at`, `calculated_at`, `imported_at`) são UTC e não exigem offset. Unidades canônicas: m, s, m/s, °C, rpm, L/100km, graus decimais e centavos inteiros com moeda ISO-4217. Em toda tabela, ausência é NULL e o motivo fica no campo `*_missing_reason` ou `missing_fields_json`; nunca zero. Todas as FKs têm `ON DELETE RESTRICT`, salvo CASCADE indicado.

## Tabelas e colunas

- `motorcycle`: `id TEXT PK`; `make TEXT NOT NULL`; `model TEXT NOT NULL`; `year INTEGER NOT NULL CHECK(year BETWEEN 1900 AND 2200)`; `vin TEXT NULL`; `nickname TEXT NULL`; `created_at TEXT NOT NULL`; `updated_at TEXT NOT NULL`. Índice único parcial em make/model/year/vin quando VIN existe.
- `odometer_reading`: `id`; `motorcycle_id TEXT NOT NULL FK motorcycle RESTRICT`; `read_at TEXT NOT NULL`; `original_offset TEXT NULL`; `value_m INTEGER NOT NULL CHECK(value_m>=0)`; `source TEXT NOT NULL CHECK(source IN ('user','maintenance','trip','import'))`; `note TEXT NULL`; `is_correction INTEGER NOT NULL DEFAULT 0 CHECK(is_correction IN (0,1))`; `corrects_reading_id TEXT NULL FK odometer_reading RESTRICT`; `created_at TEXT NOT NULL`. Regressão exige is_correction=1, referência e nota; o bruto não muda.
- `maintenance_record`: `id`; `motorcycle_id TEXT NOT NULL FK`; `occurred_at TEXT NOT NULL`; `original_offset TEXT NULL`; `type TEXT NOT NULL CHECK(type IN ('service','repair','inspection','other'))`; `description TEXT NOT NULL`; `odometer_reading_id TEXT NULL FK`; `cost_cents INTEGER NULL CHECK(cost_cents>=0)`; `currency TEXT NULL`; `cost_missing_reason TEXT NULL`; `notes TEXT NULL`; `created_at TEXT NOT NULL`; custo/moeda são ambos preenchidos ou ambos NULL.
- `maintenance_item`: `id`; `record_id TEXT NOT NULL FK maintenance_record CASCADE`; `name TEXT NOT NULL`; `quantity REAL NULL`; `part_number TEXT NULL`; `cost_cents INTEGER NULL`; `currency TEXT NULL`; `cost_missing_reason TEXT NULL`.
- `maintenance_plan`: `id`; `motorcycle_id TEXT NOT NULL FK`; `name TEXT NOT NULL`; `interval_m INTEGER NULL CHECK(interval_m>0)`; `interval_days INTEGER NULL CHECK(interval_days>0)`; `active INTEGER NOT NULL DEFAULT 1 CHECK(active IN (0,1))`; `created_at TEXT NOT NULL`; CHECK ao menos um intervalo. `plan_item(plan_id FK CASCADE,name TEXT NOT NULL,part_number TEXT NULL,PRIMARY KEY(plan_id,name))`; `record_plan(record_id FK CASCADE,plan_id FK RESTRICT,PRIMARY KEY(record_id,plan_id))`; itens executados são cópias em maintenance_item.
- `trip`: `id`; `motorcycle_id TEXT NOT NULL FK`; `started_at TEXT NULL`; `ended_at TEXT NULL`; `started_original_offset TEXT NULL`; `ended_original_offset TEXT NULL`; `status TEXT NOT NULL CHECK(status IN ('draft','recording','paused','interrupted','finished','cancelled'))`; `source TEXT NOT NULL CHECK(source IN ('gps','import','demo'))`; `distance_m INTEGER NULL`; `distance_missing_reason TEXT NULL`; `wheel_distance_m INTEGER NULL`; `wheel_distance_missing_reason TEXT NULL`; `rideology_distance_m INTEGER NULL`; `rideology_distance_missing_reason TEXT NULL`; `duration_s INTEGER NULL`; `summary_json TEXT NULL`; `created_at TEXT NOT NULL`; `updated_at TEXT NOT NULL`.
- `trip_segment`: `id`; `trip_id TEXT NOT NULL FK CASCADE`; `sequence INTEGER NOT NULL CHECK(sequence>=0)`; `started_at TEXT NOT NULL`; `ended_at TEXT NULL`; `status TEXT NOT NULL CHECK(status IN ('recording','paused','finished','interrupted'))`; UNIQUE(trip_id,sequence).
- `location_point`: `id`; `segment_id TEXT NOT NULL FK CASCADE`; `sequence INTEGER NOT NULL CHECK(sequence>=0)`; `recorded_at TEXT NOT NULL`; `original_offset TEXT NOT NULL`; `monotonic_ms INTEGER NULL`; `latitude REAL NOT NULL CHECK(latitude BETWEEN -90 AND 90)`; `longitude REAL NOT NULL CHECK(longitude BETWEEN -180 AND 180)`; `accuracy_m REAL NULL`; `altitude_m REAL NULL`; `speed_mps REAL NULL`; `source TEXT NOT NULL CHECK(source IN ('gps','demo'))`; `validity TEXT NOT NULL CHECK(validity IN ('valid','invalid'))`; `invalid_reason TEXT NULL`; CHECK(validity='valid' OR invalid_reason IS NOT NULL); UNIQUE(segment_id,sequence). GPS válido = validity valid, coordenadas dentro dos limites, accuracy não ausente e dentro de limiar [A VERIFICAR], sem salto temporal/espacial rejeitado; não válido não entra na distância oficial.
- `telemetry_import`: `id`; `motorcycle_id TEXT NOT NULL FK`; `source_file_name TEXT NOT NULL`; `source_hash TEXT NOT NULL UNIQUE`; `raw_uri TEXT NOT NULL`; `imported_at TEXT NOT NULL`; `encoding TEXT NULL`; `delimiter TEXT NULL`; `parser_version TEXT NOT NULL`; `status TEXT NOT NULL CHECK(status IN ('pending','parsed','rejected','failed'))`; `error_summary TEXT NULL`. Hash global: reimportar o mesmo conteúdo retorna o import existente, mesmo renomeado, e não duplica.
- `telemetry_session`: `id`; `motorcycle_id TEXT NOT NULL FK`; `trip_id TEXT NULL FK`; `import_id TEXT NULL FK`; `started_at TEXT NOT NULL`; `ended_at TEXT NULL`; `original_offset TEXT NOT NULL`; `source TEXT NOT NULL CHECK(source IN ('rideology_csv','ble','demo'))`; CHECK(trip_id IS NOT NULL OR import_id IS NOT NULL).
- `telemetry_sample`: `id`; `session_id TEXT NOT NULL FK CASCADE`; `row_number INTEGER NOT NULL CHECK(row_number>0)`; `recorded_at TEXT NULL`; `original_offset TEXT NULL`; `recorded_at_missing_reason TEXT NULL`; `rpm REAL NULL`; `speed_mps REAL NULL`; `gear INTEGER NULL`; `engine_temp_c REAL NULL`; `fuel_consumption_l_per_100km REAL NULL`; `values_json TEXT NULL`; `missing_fields_json TEXT NULL`; UNIQUE(session_id,row_number).
- `sample_issue`: `id`; `import_id TEXT NOT NULL FK`; `session_id TEXT NULL FK`; `sample_id TEXT NULL FK`; `row_number INTEGER NOT NULL`; `field TEXT NULL`; `code TEXT NOT NULL`; `detail TEXT NOT NULL`; CHECK(sample_id IS NOT NULL OR row_number>0). Linha rejeitada sem amostra referencia importação e linha.
- `metric_result`: `id`; `trip_id TEXT NULL FK`; `session_id TEXT NULL FK`; `metric_type TEXT NOT NULL`; `value REAL NULL`; `unit TEXT NOT NULL`; `method_version TEXT NOT NULL`; `calculation_key TEXT NOT NULL`; `coverage_json TEXT NOT NULL`; `evidence_json TEXT NOT NULL`; `calculated_at TEXT NOT NULL`; CHECK exatamente um escopo; UNIQUE(trip_id,session_id,metric_type,method_version,calculation_key). Recalcular gera nova chave/versão.
- `baseline_profile`: `id`; `motorcycle_id TEXT NOT NULL FK`; `metric_type TEXT NOT NULL`; `cohort_definition_json TEXT NOT NULL`; `sample_count INTEGER NOT NULL CHECK(sample_count>=0)`; `p50 REAL NULL`; `p90 REAL NULL`; `mean REAL NULL`; `stddev REAL NULL`; `version TEXT NOT NULL`; `calculated_at TEXT NOT NULL`; UNIQUE(motorcycle_id,metric_type,version).
- `finding`: `id`; `trip_id TEXT NULL FK`; `metric_type TEXT NOT NULL`; `kind TEXT NOT NULL CHECK(kind IN ('measurement','deviation','hypothesis','recommendation'))`; `observed_value REAL NULL`; `expected_value REAL NULL`; `deviation REAL NULL`; `confidence REAL NULL CHECK(confidence BETWEEN 0 AND 1)`; `evidence_json TEXT NOT NULL`; `classification TEXT NOT NULL`; `algorithm_version TEXT NOT NULL`; `created_at TEXT NOT NULL`.
- `report`: `id`; `scope TEXT NOT NULL CHECK(scope IN ('trip','period','maintenance'))`; `trip_id TEXT NULL FK`; `period_start TEXT NULL`; `period_end TEXT NULL`; `structured_input_json TEXT NOT NULL`; `input_hash TEXT NOT NULL`; `generation_version TEXT NOT NULL`; `narrative TEXT NOT NULL`; `uncertainty_json TEXT NOT NULL`; `generated_at TEXT NOT NULL`.

Índices: todas as FKs; motorcycle_id+tempo, segment_id+sequence, session_id+recorded_at, import_id+row_number e trip_id+metric_type. `PRAGMA foreign_keys=ON`, WAL e migrations transacionais são invariantes. Exclusão de moto com histórico é RESTRICT.
